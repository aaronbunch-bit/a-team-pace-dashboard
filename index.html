Site admin setup required (this is why Google never opens an account chooser):

  1. Open this exact site in Netlify (the one whose URL you’re on now).
  2. Go to Project configuration → Identity and click Enable Identity.
  3. Under Registration → External providers, add Google (use Netlify’s credentials).
  4. Set registration to Open.
  5. If Visitor Access / Site protection / Team login / SAML / Edge Access is on, turn it OFF — that Netlify SSO blocks Google Identity for staff who don’t have Netlify accounts.
  6. Hard-refresh this page. The button should then send you to Google’s account chooser.

Quick check: /.netlify/identity/settings must return JSON, not “Page not found”.

Only @varsitytutors.com Google accounts can open the dashboard. You do not need a Netlify account.
